# 🏨 Travel Agency Rate Maker

Hotel Rate Calculator with Seasonal Pricing & Event Supplements for **Grand Central Hotel, Dubai**.

## Features

- 📅 **Seasonal Pricing** — Automatic rate calculation based on season (Sep / Oct–Mar / Apr–Aug)
- 🎉 **Event Supplements** — Automatically applies surcharges for major events (Diwali, New Year, Gulf Food, etc.)
- 🛏️ **Extra Bed Support** — Calculate additional bed charges per room
- 📧 **Email-Ready Output** — Generates a professional greeting with booking details
- 📋 **Copy to Clipboard** — One-click copy of the full quotation
- 🖨️ **Print-Friendly** — Clean print layout for physical records
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile

## Usage

Simply open `travel-rate-maker.html` in any modern web browser. No server or dependencies required.

1. Enter the guest/agent name
2. Select check-in and check-out dates
3. Set number of rooms and extra beds
4. Click **Calculate Rates**
5. Review the breakdown and copy/print as needed
